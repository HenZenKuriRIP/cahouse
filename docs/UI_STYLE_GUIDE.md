# VOID SIGNAL · UI 风格指南（复古未来像素界面）

> 关键词：深空 · 像素精确 · 全息 · 霓虹点缀 · 极简 HUD · 战术界面 · 电影化动效
> 实现代码：`scripts/ui/ui_kit.gd`（绘制原语）、`scripts/ui/ui_theme.gd`（Theme/9-slice）、`scripts/ui/pixel_button.gd`、`scripts/ui/holo_overlay.gd`

## 1. 色板（严格限定，禁止新增饱和色）
| 名称 | 色值 | 用途 |
|---|---|---|
| BG | `#080C18` | 背景、面板底 |
| BG2 | `#10182B` | 次级面板、按钮底 |
| ACCENT 青 | `#49E6D4` | 主强调、可交互、护盾 |
| DANGER 红 | `#FF5268` | 伤害、船体、武器、失败 |
| ENERGY 金 | `#FFCC66` | 能量、超载、引擎、数值滚动 |
| RARE 紫 | `#A78BFA` | 协同/稀有、区域名 |
| TEXT | `#EAF4FF` | 正文 |
| DIM | TEXT@45% | 次要说明 |
| LINE | ACCENT@25% | 分隔线 |

规则：一个组件最多 1 个强调色 + TEXT；大面积只用 BG/BG2；发光通过同色低透明度叠层实现，不使用加色混合，避免“霓虹污染”。

## 2. 网格与安全边距
- 逻辑分辨率 270×480（竖屏），窗口 540×960，整数缩放，**所有坐标取整**（`K.px()`）。
- 基础网格 2px，组件间距 4/6/8px；屏幕安全边距 4px（HUD 卡片）/ 6px（编辑器）/ 24px（模态面板左右）。
- 战斗 HUD 只占顶部 0–40px 与底部 404–478px，中部留给战斗。

## 3. 字体与字号
- Fusion Pixel 12px（SIL OFL 1.1），只用整数倍：BODY 12、TITLE 24、LOGO 48。
- 正文带 1px 投影（BG@80%），浮动数字带 1px 描边。
- 数值右对齐；单位跟随语言（`米`/`m`）。

## 4. 面板系统（9-slice 切角）
- 16×16 程序生成图像 → `StyleBoxTexture`，切片边距 5px，4px 斜切角。
- 构成：BG 底（88%）+ 1px ACCENT 边框 + 顶部 1px 高光（TEXT@8%）+ 四角支架（brackets）+ 2px 间隔扫描线（BG@25–35%）。
- 层级：模态 > 卡片 > 芯片（chip，3px 切角）> 刻度。

## 5. 图标
- 7×7 单色像素字形（`K.ICONS`），共 21 个：hull/shield/dash/core/四种武器/play/restart/quit/lang/flash/kills/scrap/distance/time/warning/build/synergy/module。
- 图标永远与文字同色或为该语义色；2× 时整数放大。

## 6. 按钮状态（含手柄焦点）
| 状态 | 表现 |
|---|---|
| normal | BG2@92% + ACCENT@45% 边 |
| hover | ACCENT@16% 底 + ACCENT@90% 边，文字变青 |
| pressed | ACCENT@30%，内容下移 1px |
| disabled | 边 TEXT@15%，文字 DIM |
| focus（键盘/手柄） | 四角支架 + 右侧闪动光标；鼠标悬停自动获取焦点，保证同一时刻只有一个高亮 |
| switch | 右侧像素滑块，开=青色填充 |

## 7. 动效规则
- 时长：微交互 0.1s，面板展开 0.24s（从一条线展开），按钮依次淡入+滑入（间隔 0.05s），结算数值滚动 1.1s 后评级字母弹出。
- 缓动：ease_out_cubic（位移）/ ease_out_back（弹出，仅提示卡片）。
- 动效使用真实时间（不受 timescale/暂停影响）。
- 协同提示：从右侧滑入，停留 1.6s，滑出；同时最多 2 条。

## 8. HUD 信息层级
- L1 常驻核心：船体/护盾分段条（带受损残影）、能量三角、武器热量。
- L2 常驻次要：距离进度条（6 个里程碑刻度）、计时、击杀、残骸。
- L3 事件：协同提示、超载/临界芯片、过热警告、伤害方向弧、低血量暗角。
- 能量三角：轮廓同时是热量表（左下→顶→右下点亮），超载变金、临界闪红。

## 9. 无障碍
- **减少闪烁**（暂停菜单开关）：关闭全息闪烁、标题提示闪动、扫光、临界闪烁（改为常亮）。屏幕抖动由独立存档项 `screen_shake` 控制（目前没有菜单开关，见 TODO）。
- 颜色之外总有形状/文字冗余（图标 + 文本 + 位置）。
- UI 缩放：目前仅靠窗口整数缩放（canvas_items + integer），拉大窗口即 2×/3×；独立的 UI 缩放滑杆尚未实现（见 TODO）。
- 全部 UI 文本走本地化（中/英），按钮宽度按最长语言预留。
